# IntentAI

IntentAI reads customer signals in real time, identifies what they need, and instantly routes them to the AI agent built to act.

Live site: https://intentai.io

## Tech stack

- Static HTML/CSS/JS, no build step
- Space Grotesk font via Google Fonts
- Lucide icons
- Deployed via GitHub Pages with a custom domain (see CNAME)

## Structure

- index.html - landing page
- favicon.ico, favicon-192.png - site favicons
- CNAME - custom domain config for GitHub Pages
